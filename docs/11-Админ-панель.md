# 11. Админ-панель — инструкция владельцу

Админка — «пульт управления» магазином. Адрес: `https://<домен>/admin/index.html`. Пускает только администратора.

**Как войти:**
- **на сервере** — почта и пароль администратора из `deploy/.env` ([раздел 13](13-Публикация-на-сервере.md));
- **на своём компьютере с сервером** — `admin@demo.kz` / `admin12345`;
- **в демо-версии** — «Быстрый вход» → «Администратор» (`admin@demo.kz` / `admin123`).

С сервером все изменения сохраняются в базе и сразу видны всем посетителям.

## Меню

| Раздел | Для чего |
|---|---|
| **Обзор** | Выручка, заказы, товары, покупатели; последние заказы; что заканчивается; топ продаж |
| **Товары** | Список, поиск, фильтры; добавить, изменить, скрыть, скопировать, удалить |
| **Категории** | Категории и подкатегории |
| **Заказы** | Все заказы, статус заказа и оплаты. Жёлтая цифра — новые заказы |
| **Пользователи** | Покупатели: заблокировать, разблокировать, удалить |
| **Отзывы** | Ответить, скрыть, удалить. Жёлтая цифра — отзывы без ответа |
| **Фото «О нас»** | Замена 6 фото блока «Жизнь магазина» |
| **Настройки** | «Готовность к запуску» (почта, оплата, предупреждения) и выгрузка данных в файл |

Тексты сайта (заголовки, кнопки, «О нас», доставка) в админке **не меняются** — только в файлах ([раздел 12](12-Тексты-фото-и-частые-правки.md)).

## Карточка товара

Форма разбита на разделы; строка-навигация вверху переводит к нужному.

### Основное
| Поле | Что писать | Где видно |
|---|---|---|
| **Название** * | Тип средства + бренд + линия: «Успокаивающий тонер Anua Heartleaf 77%» | Везде |
| **Бренд** * | Подсказывает уже введённые бренды | Карточка, фильтр «Бренд» |
| **Адрес страницы** | Создаётся сам латиницей из названия | `pages/product.html?slug=…` |
| **Категория / подкатегория** | Из списка или «＋ Новая…» | Каталог, «хлебные крошки» |
| **Краткое описание** | 1–2 предложения, до 220 символов | Рядом с ценой |
| **Полное описание** | Подробный текст | Вкладка «Описание» |

### Фото
- Нажмите «Выберите файлы» или перетащите фото мышкой; можно несколько сразу. Фото автоматически уменьшаются и загружаются на сервер.
- **Первое фото — главное**, второе показывается при наведении на карточку. ← → меняют порядок, ★ — сделать главным, 🗑 — удалить.
- Совет: 3 фото — общий вид, текстура крупно, товар в руке.

### Для чего и кому
Главное для покупателя; работает как **фильтры каталога**.

| Поле | Как заполнять | Пример |
|---|---|---|
| **Для чего** | Метки: какие задачи решает. Enter или запятая — добавить | «Увлажнение», «Спокойствие и сон» |
| **Кому подходит** | Тип кожи, волос, человека | «Чувствительная кожа», «Для всей семьи» |
| **Что даёт** | Список результатов | «Успокаивает и снимает покраснения» |
| **Теги** | Для поиска и подборок | «без спирта», «подарок» |

> Пишите метки одинаково во всех товарах («Увлажнение», а не то «увлажнение», то «Увлажняет») — помогают подсказки.

### Состав, применение, характеристики
- **Ключевые компоненты** — «Компонент — что делает» (на сайте — карточки); **полный состав** — с упаковки.
- **Когда применять** (утро/день/вечер), **как часто**, **шаги**, **меры предосторожности** (жёлтая рамка; для трав — «Не является лекарством…»).
- Объём, страна, срок годности, артикул и любые строки «название — значение» (текстура, аромат…).

### Свои разделы
«＋ Добавить раздел» — своя вкладка на странице товара (материал, хранение, сертификаты…). Пустая строка — новый абзац, строки с «- » — список.

### Справа
- **Публикация:** «На сайте» или «Скрыт» (скрытый не виден покупателям, но не удаляется).
- **Цена и наличие:** цена, старая цена (появится плашка «−15%»), остаток. При 0 — «Нет в наличии».
- **Метки:** «Хит», «Новинка», «Популярное».
- **Заполненность** карточки и **превью**.

Внизу — «Сохранить». Если уйти, не сохранив, админка переспросит.

## Список товаров
Поиск по названию, бренду, тегу, артикулу; фильтры по категории, наличию, публикации. **Остаток** меняется прямо в таблице (Enter).
В строке: 👁 скрыть/показать, ↗ открыть на сайте, ✏️ изменить, ⧉ копия (создаётся скрытой), 🗑 удалить.
Галочками можно скрыть, показать или удалить несколько товаров сразу.

## Категории
Меняйте названия, добавляйте подкатегории, «Сохранить». Категорию с товарами удалить нельзя — сначала перенесите товары.

## Заказы
Нажмите на заказ: покупатель, адрес, состав, способ и статус оплаты.

| Статус заказа | Когда ставить |
|---|---|
| Новый | Только пришёл |
| В обработке | Связались с покупателем, собираете |
| Отправлен | Передан в доставку |
| Выполнен | Покупатель получил |
| Отменён | Отменён — товары возвращаются на склад, в выручке не учитывается |

**Оплата:** при переводе на Kaspi после поступления денег выберите **«Оплачен»**. Тестовая оплата и Kaspi Pay отмечают оплату сами.
После «Отправлен» и «Выполнен» у покупателя появляется кнопка «Оценить».

## Отзывы
Вкладки «Все», «Без ответа», «Опубликованные», «Скрытые»; поиск и фильтр по оценке.
**Ответить** — ответ появится под отзывом с пометкой «Ответ магазина». **Скрыть** — пропадёт с сайта и из рейтинга, но останется в админке.
**Удалить** — навсегда. Рейтинг считается только по опубликованным отзывам.

## Пользователи
Заблокировать (не сможет войти), разблокировать, удалить. Администратора заблокировать или удалить нельзя — он задаётся в `deploy/.env`.

## Фото «О нас»
Шесть фото мозаики «Жизнь магазина». У каждого — **«Заменить фото»** и, если фото заменено, **«Вернуть исходное»**.
Подписи к фото меняются в `frontend/texts/ru/about.js`.

## Настройки
- **«Готовность к запуску»:** работает ли отправка писем, какие способы оплаты включены и готовы, и предупреждения о небезопасных настройках сервера. Сами пароли здесь не показываются.
- **Экспорт JSON** — скачать товары, категории, заказы и отзывы файлом.
- Полные резервные копии базы и фото делает сервер ежедневно ([раздел 8](08-База-данных.md)).
