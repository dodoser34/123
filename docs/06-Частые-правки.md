# 6. Частые правки

Файлы `.js`, `.css` и `.html` — это обычный текст. Их можно открыть в любом текстовом редакторе. Удобнее всего бесплатный **Visual Studio Code**: он подсвечивает код цветом. Блокнот Windows тоже подойдёт.

**Три правила безопасной правки:**
1. **Перед правкой сделайте копию файла**, например `config.js` → `config — копия.js`.
2. Меняйте **только текст внутри кавычек** `'вот здесь'`. Кавычки, запятые и скобки не трогайте.
3. После сохранения **обновите страницу в браузере** (`Ctrl + F5`, чтобы браузер точно взял новую версию). Если что-то сломалось, верните копию.

> **Если у посетителей остаётся старая версия.** Браузеры запоминают файлы сайта. Чтобы все сразу получили новую версию, увеличьте число версии: `VERSION = '10'` в `site/assets/js/app.js`, `?v=10` в строке подключения `app.js` и стилей в каждом HTML-файле и в `@import` внутри `assets/css/main.css` и `admin.css`. Проще всего это сделать заменой по всем файлам в VS Code (`Ctrl + Shift + H`: `?v=10` → `?v=11`).

## Телефон WhatsApp, email, соцсети, адрес
Файл: `site/assets/js/config.js` — в нём собраны все настройки магазина.

```js
App.config = {
  shopName: 'K-Beauty | C-Health',
  whatsapp: '77000000000',   // номер ТОЛЬКО цифрами, с 7 в начале, без + и пробелов
  email: 'hello@kbeauty-chealth.kz',
  address: '',               // адрес магазина
  mapUrl: '',                // ссылка на карту
  instagram: 'https://instagram.com/',
  ...
```

- **WhatsApp:** номер `+7 701 123 45 67` записывается как `'77011234567'`. Этот номер используется во всех кнопках «Написать» на сайте.
- **Адрес** сейчас **намеренно пустой**. Пока он пустой, сайт нигде не показывает адрес и ссылку «Показать на карте», а про самовывоз пишет «Адрес уточняйте в WhatsApp». Когда адрес понадобится, впишите его, например `address: 'г. Костанай, ул. Абая, 10'`. Он сам появится в подвале, на «О нас», в «Доставке» и при оформлении заказа.
- **mapUrl:** откройте место в 2ГИС или Яндекс.Картах → «Поделиться» → скопируйте ссылку и вставьте между кавычками.

## Бесплатная доставка и цена курьера
Там же, в `App.config`:
```js
freeShippingFrom: 15000,  // от какой суммы курьер бесплатно
courierPrice: 1000,       // цена курьера по городу
```

## Тексты страницы «Доставка и оплата», таблица сроков, вопросы-ответы
Файл: `site/assets/js/data/delivery-info.js`. Каждая строка таблицы выглядит так:
```js
['Астана, Алматы', '2–4 дня', 'по тарифу службы'],
```
Чтобы добавить вопрос, скопируйте строку внутри `faq: [...]` и поменяйте текст:
```js
['Ваш вопрос?', 'Ваш ответ.'],
```

## Тексты на главной и «О нас»
Эти тексты лежат прямо в HTML-файлах `site/index.html` и `site/about.html`. Найдите нужную фразу поиском (`Ctrl + F`) и замените её. Не удаляйте символы `<` `>` вокруг текста — это разметка.

Цифры на странице «О нас» («1 298 довольных клиентов») задаются в `about.html` в атрибуте `data-count="1298"`.

## Товары, цены, фото
Через **админку** — см. [раздел 5](05-Инструкция-по-админке.md). Править код для этого не нужно.

Демо-товары лежат в `site/demo/data/products.js`. Для настоящего магазина папку `site/demo` удаляют целиком — см. раздел «Запуск без демо» ниже.

## Фото на сайте
Просто положите файл с **точно таким же именем** в нужную папку и замените старый:
- главный баннер — `site/assets/images/pages/home/hero.jpg`;
- фото настоящего товара — `site/assets/images/products/<категория>/<имя>.jpg`, например `products/face/anua-toner.jpg`, и этот путь указывается в админке (фото демо-товаров лежат в `site/demo/images/products/`);
- дополнительные ракурсы товара — рядом, с `-2` и `-3` в имени: `anua-toner-2.jpg`, `anua-toner-3.jpg`. Они сами появятся в галерее на странице товара;
- фотогалерея «Жизнь магазина» на «О нас» — `site/assets/images/pages/about/gallery-1.jpg` … `gallery-6.jpg`.

Полный список имён и размеров — в `prompts/IMAGES.md`.

## Цвета
Файл `site/assets/css/base/variables.css` — в нём только настройки дизайна.
```css
--bg: #F3EFE6;        /* фон страницы (кремовый) */
--primary: #1F3A2D;   /* фирменный тёмно-зелёный: кнопки, акценты */
--text: #22251F;      /* основной текст */
```
Замените код цвета (например `#1F3A2D` → `#2D4A3A`), и цвет изменится **на всём сайте сразу**. Коды цветов удобно подбирать на сайте htmlcolorcodes.com.

## Шрифты
Используются бесплатные шрифты Google Fonts:
- **Cormorant Garamond** — заголовки (изящный, с засечками);
- **Manrope** — обычный текст;
- **Caveat** — рукописные фразы.

Они подключаются строкой `<link href="https://fonts.googleapis.com/...">` в каждом HTML-файле и задаются в `assets/css/base/variables.css` (`--font-serif`, `--font-sans`, `--font-hand`). Смену шрифта лучше поручить разработчику: строку подключения нужно поменять во всех HTML-файлах одинаково.

## Название магазина и логотип
- Название: `shopName` в `assets/js/config.js`. Оно показывается в шапке, подвале и админке. В заголовках вкладок браузера название вписано в каждый HTML-файл (тег `<title>`).
- Логотип-лотос нарисован кодом (SVG) в `site/assets/js/core/icons.js`, переменная `ui.logoSvg`. Чтобы поставить свой логотип, передайте разработчику файл в формате SVG.

## Демо-аккаунты
Файл `site/demo/data/accounts.js`: имена, email, пароли и подписи на карточках входа. Чтобы изменения применились в вашем браузере, в админке нажмите **Настройки → «Сбросить к демо-данным»**: данные хранятся в памяти браузера и сами не обновятся.

## Запуск без демо
1. Удалите папку `site/demo` целиком.
2. В `site/assets/js/config.js` впишите email владельца: `adminEmails: ['owner@kbeauty-chealth.kz']`.
3. Зарегистрируйтесь на сайте с этим email — аккаунт сразу получит доступ к админ-панели.
4. Добавьте товары через админку.

В браузерах, где сайт уже открывали, демо-товары, отзывы, заказы и демо-аккаунты удалятся сами. Товары, добавленные администратором, останутся.

## Скорость анимаций
- Автопрокрутка каруселей — `INTERVAL` в начале `site/assets/js/components/carousel.js` (в миллисекундах).
- Переходы между страницами — длительности (`.5s`, `.24s`) в `site/assets/css/components/transitions.css`.
