# 9. Ограничения и следующие шаги

## Демо-режим и режим с сервером

Всё, что ниже в таблице, относится **только к демо-режиму** (без сервера, `frontend/env.js` пустой). С подключённым сервером
([раздел 11](11-Бэкенд-и-деплой.md)) эти ограничения сняты.

| Что | В демо-режиме | С сервером |
|---|---|---|
| **Товары из админки** | Только в браузере администратора | В базе, видны всем |
| **Заказы** | В браузере покупателя — владелец их не получит | В базе, видны в админке |
| **Аккаунты и пароли** | В браузере, упрощённая защита | На сервере, пароли — `bcrypt`, подтверждение почты, вход через Google |
| **Права администратора** | Проверяются в браузере | Проверяются сервером; администратор один, задаётся в `.env` |
| **Оплата** | Демо-карта, деньги не списываются | Перевод на Kaspi владельца; Kaspi Pay — после подключения |
| **Фото из админки** | В браузере, до ~5 МБ | Файлы на сервере |
| **Отзывы, тексты, фото сайта** | В браузере автора | Общие для всех |

## Что осталось сделать для настоящего магазина

### Шаг 1. Запустить сервер ✅ сделано в проекте
Бэкенд на FastAPI + PostgreSQL уже в папке `backend/`. Нужно только развернуть его (свой сервер с Docker или Render — [раздел 11](11-Бэкенд-и-деплой.md)),
заполнить `deploy/.env` (почта и пароль администратора, почта для писем, реквизиты Kaspi, ключи Google; см. разделы 11 и 15) и наполнить каталог.

### Шаг 2. Уведомления о заказах
Отправка нового заказа владельцу в WhatsApp, Telegram или на почту.

### Шаг 3. Онлайн-оплата
Перевод на Kaspi и наличные уже работают. Kaspi Pay (оплата в приложении с автоматическим подтверждением) готов к включению — нужны ключи из кабинета Kaspi Pay ([раздел 14](14-Платежи.md)). Другой платёжный сервис добавляется по той же схеме.

### Шаг 4. Публикация
- Купить домен (например `kbeauty-chealth.kz`) и VPS-сервер, затем выполнить шаги из [раздела 11](11-Бэкенд-и-деплой.md). HTTPS, страница 404, резервные копии и защита уже настроены.
- Для показа без сервера сайт публикуется на GitHub Pages автоматически (демо-режим).

### Шаг 5. Перед запуском
- [ ] **Удалить папку `demo`** (демо-товары, отзывы, демо-аккаунты, демо-заказы и их фото) и вписать email владельца в `adminEmails` (`js/config.js`). Подробно — `demo/README.md`.
- [ ] Заполнить WhatsApp, email, соцсети и при необходимости адрес (`js/config.js`).
- [ ] Проверить тексты, цены и условия доставки (`texts/ru/delivery.js`).
- [ ] Завести настоящие товары и фото через админку.
- [ ] Заменить фото «Жизнь магазина» на странице «О нас» (`assets/images/pages/about/gallery-*.jpg`) на настоящие.
- [ ] Пройти чек-лист безопасности из [раздела 15](15-Безопасность.md).
- [ ] Добавить страницу «Политика конфиденциальности» (обязательно, раз сайт собирает имя и телефон).
- [ ] Подключить Яндекс.Метрику или Google Analytics.
- [ ] Указать реальные цифры на странице «О нас».
