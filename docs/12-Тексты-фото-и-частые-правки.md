# 12. Тексты, фото и частые правки

Товары, цены, категории, заказы и фото «О нас» меняются в **админке** ([раздел 11](11-Админ-панель.md)).
Всё остальное — надписи сайта, контакты, цвета — в файлах. Это обычный текст: удобнее всего открывать в бесплатном **Visual Studio Code**.

**Три правила безопасной правки:**
1. Перед правкой сделайте копию файла.
2. Меняйте **только текст внутри кавычек** `'вот здесь'`; кавычки, запятые и скобки не трогайте.
3. После сохранения обновите страницу (`Ctrl + F5`). Если что-то сломалось — верните копию.

> **Чтобы посетители сразу получили новую версию** после публикации, увеличьте номер версии: `VERSION = '23'` в `frontend/js/app.js`
> и `?v=23` в строках подключения в HTML-файлах (во всех одинаково; в VS Code — `Ctrl + Shift + H`, заменить `?v=23` на `?v=24`).

## Надписи сайта

Все надписи — в `frontend/texts/ru/`, по файлу на раздел:

| Файл | Что внутри |
|---|---|
| `common.js` | Шапка, меню, подвал, три преимущества, кнопки, уведомления, окна «Вы уверены?», статусы заказов, ошибки |
| `home.js` | Главная |
| `catalog.js` | Каталог, фильтры, «Ничего не найдено» |
| `product.js` | Страница товара, вкладки, отзывы, форма отзыва |
| `about.js` | О нас: миссия, цифры (`stats`), «Почему нам доверяют», **подписи к 6 фото** (`gallery.photos`), контакты |
| `delivery.js` | Доставка и оплата: способы, **таблица сроков**, **частые вопросы** |
| `cart.js`, `checkout.js`, `pay.js` | Корзина, оформление, оплата |
| `login.js`, `account.js` | Вход и регистрация, личный кабинет |
| `favorites.js`, `not-found.js` | Избранное, страница 404 |

Откройте файл, найдите фразу (`Ctrl + F`), замените текст в кавычках.
- `<br>` — перенос строки.
- `{count}`, `{name}`, `{sum}` — сюда сайт подставит число, имя, сумму. **Не удаляйте их.**
- `{count|товар|товара|товаров}` — слово в нужной форме для числа («1 товар», «3 товара», «5 товаров»).

Строка таблицы сроков в `delivery.js` — три значения (город/способ, срок, стоимость):
```js
['Костанай — курьер', 'в день заказа / 1 день', '1 000 ₸, бесплатно от 15 000 ₸'],
```
Вопрос-ответ — два значения: `['Как отследить заказ?', 'После отправки мы пришлём трек-номер…']`.

## Контакты, адрес, доставка

Файл `frontend/js/config.js`:
```js
App.config = {
  shopName: 'K-Beauty | C-Health',
  tagline: 'Корейская косметика и натуральные травы',
  email: 'hello@kbeauty-chealth.kz',
  address: '',
  mapUrl: '',
  freeShippingFrom: 15000,
  courierPrice: 1000,
  adminEmails: []
};
```
- **address** — адрес магазина. Пока пусто, адрес и «Показать на карте» нигде не показываются. Впишите, например, `'г. Костанай, ул. Абая, 10'` — он появится в подвале, «О нас», «Доставке» и при оформлении.
- **mapUrl** — ссылка из 2ГИС или Яндекс.Карт («Поделиться» → скопировать).
- **freeShippingFrom**, **courierPrice** — бесплатная доставка от суммы и цена курьера. На сервере сумму доставки считает сервер — эти же значения задаются в `deploy/.env` (`FREE_SHIPPING_FROM`, `COURIER_PRICE`).
- **adminEmails** — только для режима без сервера: кто зарегистрируется с этой почтой, получит доступ к админке.

## Фото оформления сайта

Положите файл **с тем же именем** в ту же папку `frontend/assets/images/` (заменив старый):

| Где на сайте | Файл |
|---|---|
| Первый экран главной | `pages/home/hero-background.jpg` (фон) и `pages/home/hero-products.webp` (косметика с прозрачным фоном) |
| Баннер категорий | `pages/home/categories-bg.jpg` |
| «О нас»: магазин | `pages/about/about-shop.jpg` |
| «О нас»: мозаика «Жизнь магазина» | `pages/about/gallery-1.jpg` … `gallery-6.jpg` — проще заменить в админке |
| «Доставка» | `pages/delivery/delivery-side.jpg` |
| Страница входа | `pages/login/auth-side.jpg` |
| Превью для соцсетей | `common/og-image.jpg` |
| Украшения-веточки | `decor/*.png` (прозрачный фон, не больше 1100 px) |

Готовое задание для нейросети на все эти фото с размерами и требованиями — [Промпт для Codex](Промпт-для-Codex-фото-сайта.md).
Фото **товаров** загружаются в админке.

## Цвета и шрифты

Файл `frontend/css/base/variables.css`:
```css
--bg: #F3EFE6;        фон страницы (кремовый)
--primary: #1F3A2D;   фирменный тёмно-зелёный: кнопки, акценты
--text: #22251F;      основной текст
```
Замените код цвета — он изменится на всём сайте сразу. Подбирать коды удобно на htmlcolorcodes.com.

Шрифты (Google Fonts, все с кириллицей): **Cormorant Garamond** — заголовки, **Manrope** — текст, **Caveat** — рукописные фразы.
Смену шрифта лучше поручить разработчику: строку подключения нужно поменять во всех HTML-файлах.

## Название и логотип

Название — `shopName` в `js/config.js` (шапка, подвал, админка); в заголовках вкладок — в тексте `meta` каждого раздела `texts/ru/`.
Логотип-лотос нарисован кодом (SVG) в `frontend/js/core/icons.js`; свой логотип передайте разработчику в формате SVG.
