# 1. Что это за проект

## Коротко
«K-Beauty | C-Health» — интернет-магазин корейской косметики и натуральных лечебных трав (Казахстан, г. Костанай). Сайт уже выглядит и работает как настоящий магазин:

- покупатель может смотреть каталог, искать товары, фильтровать их по категориям, цене и назначению («для чего»);
- читать и оставлять отзывы с оценкой, достоинствами и недостатками;
- откладывать товары в избранное и корзину;
- оформлять заказ с **демо-оплатой** картой или наличными при получении;
- регистрироваться или входить под готовым **демо-аккаунтом**, видеть свои заказы и отзывы;
- владелец магазина в **админке** заполняет карточки товаров (для чего, кому, теги, состав, применение), обрабатывает заказы, отвечает на отзывы и управляет пользователями.

## Важная оговорка: это «витрина без склада»
Сейчас сделана только **внешняя часть сайта** (её называют *фронтенд*). У сайта пока нет своего сервера с общей базой данных (это называют *бэкенд*).

Что это значит на практике: все данные (товары, заказы, аккаунты) хранятся **в памяти браузера** того человека, который открыл сайт. Если владелец добавит товар в админке на своём ноутбуке, покупатель на своём телефоне этого товара не увидит.

Для показа, согласования и тестирования этого достаточно. Чтобы магазин заработал по-настоящему, нужно подключить бэкенд. Подробнее — в разделе [9. Ограничения и следующие шаги](09-Ограничения-и-следующие-шаги.md).

## Из чего состоит проект

```
Наргиз/
├─ references/   ← картинки-макеты: как сайт должен выглядеть
├─ prompts/      ← задание для нейросети: какие фото сгенерировать для сайта
├─ site/         ← САМ САЙТ (всё, что увидит покупатель)
└─ docs/         ← эта документация
```

- **references** — «эскизы» дизайнера. По ним верстался сайт.
- **prompts/IMAGES.md** — подробный список всех фото, которые нужны сайту, с описанием каждого кадра. Его отдают нейросети (например, Codex), и она создаёт картинки.
- **site** — готовый сайт. Именно эту папку загружают на хостинг.
- **docs** — то, что вы читаете.

## Как открыть сайт у себя на компьютере

**Способ 1 — самый простой.** Откройте папку `site` и дважды щёлкните по файлу `index.html`. Сайт откроется в браузере.

**Способ 2 — правильный (через локальный сервер).** В первом способе браузер иногда ограничивает работу файлов, открытых напрямую с диска. Надёжнее запустить маленький «домашний сервер». Для этого нужен установленный Python. Откройте терминал в папке `Наргиз` и выполните команду:

```bash
python -m http.server 5173 --directory site
```

После этого откройте в браузере адрес **http://localhost:5173**. Чтобы остановить сервер, нажмите в терминале `Ctrl + C`.

## Как войти: демо-аккаунты
На странице «Вход» (иконка человечка в шапке) можно зарегистрироваться или войти. Под формой входа есть блок «Быстрый вход для проверки» с двумя готовыми аккаунтами, вход в один клик:

- **Покупатель** (`buyer@demo.kz` / `demo123`) — корзина, избранное, оформление заказа, личный кабинет с готовыми заказами и отзывами;
- **Администратор** (`admin@demo.kz` / `admin123`) — сразу открывает админ-панель (`/admin/index.html`).

Логины и пароли также написаны на карточках и в файле `site/demo/data/accounts.js`.

## Демо-наполнение — отдельная папка
Все демо-данные (товары, отзывы, демо-аккаунты, демо-заказы) и фото демо-товаров лежат в одной папке `site/demo/`. Перед запуском настоящего магазина её просто удаляют — подробно в `site/demo/README.md`.

## Фото
Фото страниц лежат в `site/assets/images/`, фото демо-товаров — в `site/demo/images/products/`, разложенные по папкам. Дополнительные ракурсы товаров (2-е и 3-е фото в галерее) создаст нейросеть по заданию из `prompts/IMAGES.md`. Когда файлы появятся в папках с нужными именами, они подставятся сами, ничего переделывать не нужно. Если какого-то фото нет, сайт показывает аккуратную заглушку с лотосом.
