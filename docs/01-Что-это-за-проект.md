# 1. Что это за проект

## Коротко

**K-Beauty | C-Health** — интернет-магазин корейской косметики и лечебных трав для Казахстана.
Покупатель выбирает товары в каталоге, кладёт в корзину и оформляет заказ; владелец управляет магазином через админ-панель.

## Что умеет магазин

**Для покупателя:**
- главная страница, каталог с категориями, поиском, фильтрами («Для чего», бренд, цена) и сортировкой;
- страница товара: фото, описание, состав, применение, характеристики, отзывы, похожие товары;
- избранное и корзина — работают без регистрации;
- регистрация с подтверждением почты кодом из письма, вход по почте и паролю, «Забыли пароль?»;
- оформление заказа: доставка курьером, по Казахстану или самовывоз; оплата переводом на Kaspi, наличными
  или **тестовой оплатой** картой и через Kaspi (имитация, деньги не списываются);
- личный кабинет: мои заказы и их статус, мои отзывы, профиль, смена пароля, удаление аккаунта;
- отзывы с оценками, «полезно», ответами магазина и отметкой «Покупка подтверждена».

**Для владельца (админ-панель):** обзор продаж, товары, категории, заказы и их оплата, отзывы, пользователи,
замена фото на странице «О нас», проверка «готовности к запуску».

**Смотреть сайт можно без регистрации.** Вход нужен только для оформления заказа, личного кабинета, отзывов и админки.

## Из каких частей состоит

| Часть | Что это простыми словами | Папка |
|---|---|---|
| **Фронтенд** | Сам сайт — то, что видит человек в браузере: страницы (HTML), оформление (CSS), поведение (JavaScript) | `frontend/` |
| **Бэкенд** | Программа на сервере (Python): аккаунты, товары, заказы, оплата, проверка прав | `backend/` |
| **База данных** | PostgreSQL — хранилище всех записей магазина | на сервере |
| **Публикация** | Настройки, чтобы запустить всё на сервере в интернете | `deploy/`, `render.yaml` |
| **Демо-версия** | Отдельная витрина для показа с примерами товаров (GitHub Pages) | `demo/` |
| **Тесты** | Автоматические проверки, что всё работает | `backend/tests/`, `tests/`, `demo/tests/` |
| **Документация** | То, что вы читаете | `docs/` |

## Два режима работы сайта

| Режим | Где хранятся данные | Для чего |
|---|---|---|
| **С сервером** | В базе PostgreSQL на сервере — общие для всех посетителей | Настоящий магазин |
| **Без сервера** | В памяти браузера каждого посетителя | Показ, проверка дизайна, демо на GitHub Pages |

Режим выбирается одной строкой в файле `frontend/env.js` (адрес сервера). При публикации она подставляется автоматически.

## Главные технологии

- **Сайт:** HTML, CSS и JavaScript без фреймворков — обычные файлы, которые браузер открывает сразу.
- **Сервер:** Python и FastAPI.
- **База данных:** PostgreSQL.
- **Публикация:** Docker, Nginx, бесплатный HTTPS-сертификат Let's Encrypt.
