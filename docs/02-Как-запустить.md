# 2. Как запустить на своём компьютере

Нужен **Python 3.11 или новее** (python.org). Все команды выполняются в терминале из папки проекта.
Файлы настроек (`.env`) для запуска на своём компьютере **не нужны**.

## Вариант 1. Демо-версия — самый быстрый способ посмотреть магазин

```bash
python demo/serve.py
```

Откройте **http://localhost:5175**. Это витрина с 21 примерным товаром, отзывами и заказами; всё хранится в браузере.
На странице входа есть «Быстрый вход»:

| Аккаунт | Почта | Пароль |
|---|---|---|
| Покупатель | `buyer@demo.kz` | `demo123` |
| Администратор | `admin@demo.kz` | `admin123` |

Подробнее — [раздел 15](15-Демо-версия.md). Остановить — `Ctrl + C`.

## Вариант 2. Настоящий магазин: сайт + сервер

Так магазин работает и на сервере в интернете, только база — маленький файл вместо PostgreSQL.

**Первый раз** установите библиотеки (один раз):

```bash
python -m venv backend/.venv
```
```bash
backend\.venv\Scripts\pip install -r backend/requirements-dev.txt
```
(на macOS/Linux: `backend/.venv/bin/pip …`)

**Окно терминала 1 — сервер:**

```bash
cd backend
```
```bash
.venv\Scripts\python -m uvicorn app.main:app --reload --port 8000
```

При первом запуске сервер сам создаёт базу `backend/dev.db` и категории каталога. Администратор — `admin@demo.kz` / `admin12345`.
Письма с кодами (подтверждение почты, сброс пароля) не отправляются, а записываются в файл `backend/dev-mail.log`.

**Окно терминала 2 — сайт:**

```bash
python deploy/serve_frontend.py
```

В файле `frontend/env.js` впишите адрес сервера: `window.KBCH_API_URL = 'http://localhost:8000/api';`
и откройте **http://localhost:5174**. Чтобы вернуться к режиму без сервера — `window.KBCH_API_URL = '';`
(не отправляйте в GitHub `env.js` с адресом localhost).

**Примеры товаров в локальную базу** (по желанию, только для своего компьютера):

```bash
backend\.venv\Scripts\python demo/seed_backend.py
```

Описание всех адресов сервера (API) с возможностью попробовать — http://localhost:8000/api/docs.

## Вариант 3. Только сайт, без сервера и без демо

```bash
python deploy/serve_frontend.py
```

Магазин откроется пустым: товары добавляются в админке и хранятся в браузере. Чтобы попасть в админку,
впишите свою почту в `adminEmails` в файле `frontend/js/config.js` и зарегистрируйтесь с ней.

## Почему не `python -m http.server`

Страница загружает несколько десятков файлов одновременно, а стандартный сервер Python принимает всего 5 соединений
в очереди — часть файлов иногда «теряется». `deploy/serve_frontend.py` от этого избавлен, не кеширует файлы (правки видны сразу)
и показывает страницу 404 для неверных адресов — как настоящий сервер.

## Тестовая оплата

При оформлении заказа с сервером доступны способы «Банковская карта (тестовая оплата)» и «Kaspi (тестовая оплата)».
Тестовые карты: `4242 4242 4242 4242` — оплата проходит, `4000 0000 0000 0002` — банк отклоняет; срок — любой будущий, CVC — любые 3 цифры.
Подробнее — [раздел 10](10-Оплата.md).
