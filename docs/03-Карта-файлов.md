# 3. Карта файлов

Всё, что относится к сайту, лежит в папке `site/`. Правило простое: **HTML-страницы — в корне, всё остальное — в `assets/`** (по-английски «ресурсы»), по папкам.

```
site/
├─ index.html … 404.html   ← страницы сайта
├─ admin/index.html         ← админ-панель
├─ README.md                ← краткая техническая справка
├─ demo/                    ← ДЕМО-НАПОЛНЕНИЕ: товары, отзывы, демо-аккаунты, фото товаров (можно удалить целиком)
└─ assets/
   ├─ css/      ← оформление
   ├─ js/       ← логика
   └─ images/   ← фотографии
```

## Страницы (HTML) — `site/`

| Файл | Что это | Пример адреса |
|---|---|---|
| `index.html` | Главная | `/index.html` |
| `catalog.html` | Каталог | `/catalog.html?cat=herbs` |
| `product.html` | Страница товара. Какой именно товар — указано в адресе после `slug=` | `/product.html?slug=romashka` |
| `about.html` | О нас и контакты | `/about.html` |
| `delivery.html` | Доставка и оплата | `/delivery.html` |
| `cart.html` | Корзина | `/cart.html` |
| `checkout.html` | Оформление заказа | `/checkout.html` |
| `favorites.html` | Избранное | `/favorites.html` |
| `login.html` | Вход и регистрация, быстрый вход в демо-аккаунты | `/login.html`, `/login.html?mode=register` |
| `account.html` | Личный кабинет | `/account.html` |
| `404.html` | «Страница не найдена» | — |
| `admin/index.html` | Админ-панель | `/admin/index.html` |

> **Один шаблон на все товары.** Отдельного файла для каждого товара нет: `product.html` по адресу понимает, какой товар показать. Поэтому новый товар из админки сразу получает свою страницу.

## Логика (JavaScript) — `site/assets/js/`

| Папка / файл | Роль |
|---|---|
| `app.js` | **Загрузчик.** Подключён в каждой странице одной строкой и подгружает остальные файлы в правильном порядке |
| `config.js` | ⭐ **Настройки магазина**: название, WhatsApp, email, соцсети, порог бесплатной доставки, цена курьера |
| **`core/`** | Ядро |
| `core/utils.js` | Мелкие помощники: формат цены `12 990 ₸`, ссылки, защита текста |
| `core/icons.js` | Все иконки и логотип-лотос |
| `core/start.js` | Запуск: рисует шапку и подвал, даёт страницам сигнал «начинать» |
| **`data/`** | Постоянные данные магазина |
| `data/categories.js` | Категории и подкатегории |
| `data/delivery-info.js` | ⭐ Тексты страницы «Доставка и оплата», таблица сроков, вопросы-ответы |
| **`store/`** | «Склад» `App.db`: хранит и выдаёт данные |
| `store/storage.js` | Общая «полка»: чтение и запись в память браузера |
| `store/products.js`, `categories.js`, `reviews.js` | Товары, категории, отзывы |
| `store/users.js`, `session.js` | Аккаунты и «кто сейчас вошёл» |
| `store/cart.js`, `favorites.js` | Корзина и избранное |
| `store/orders.js` | Заказы |
| `store/seed.js` | Первое заполнение «склада», сброс и **обновления данных** (миграции): когда меняется формат товаров или пути к фото, старые данные в браузере дописываются сами |
| **`components/`** | Общие детали интерфейса |
| `header.js` | Шапка, выпадающий каталог, поиск с подсказками, счётчики |
| `mobile-menu.js` | Мобильное меню |
| `footer.js`, `benefits.js` | Подвал и блок преимуществ |
| `product-card.js` | Карточка товара и звёзды |
| `images.js` | Картинки и заглушки, если фото ещё нет |
| `lightbox.js` | Просмотр фото на весь экран со стрелками |
| `toast.js`, `modal.js` | Уведомления и окна («Вы уверены?») |
| `carousel.js`, `reveal.js` | Карусель с автопрокруткой и плавное появление блоков |
| `transitions.js` | Плавные переходы между страницами, «перелёт» фото товара, перестановка карточек, бегунок вкладок, товар «улетает» в корзину |
| `cart-favorites-actions.js` | Кнопки «В корзину» и «♡» на любой странице |
| **`pages/`** | Логика каждой страницы |
| `home.js`, `about.js`, `delivery.js`, `cart.js`, `favorites.js`, `login.js`, `account.js` | Одноимённые страницы |
| `catalog.js` + `catalog-filters.js` + `catalog-toolbar.js` | Каталог; боковые фильтры; сортировка, цена, вид |
| `product.js` + `product-info.js` | Страница товара; вкладки «Описание», «Состав», «Применение», «Характеристики» |
| `product-reviews.js` + `product-review-form.js` | Список отзывов со сводкой; форма «Оставить отзыв» |
| `checkout.js` + `checkout-payment.js` | Оформление заказа; демо-оплата картой (проверка номера, срока, CVC) |
| **`admin/`** | Админка, по файлу на раздел |
| `admin-app.js` | Каркас: проверка доступа, меню, переключение разделов |
| `dashboard.js` | «Обзор» |
| `products-list.js` | Список товаров, массовые действия, копирование |
| `product-form-template.js` | Разметка формы товара: все разделы и поля |
| `product-form.js` | Работа формы: заполнение, проверка, сохранение, «заполненность» |
| `form-controls.js` | Поля-метки («Для чего», «Теги»), списки строк, пары «название — значение» |
| `product-images.js`, `image-tools.js` | Блок фото товара; уменьшение фото |
| `categories.js`, `orders.js`, `users.js`, `reviews.js`, `settings.js` | Остальные разделы |

⭐ — файлы, которые чаще всего правят. Как именно — в [разделе 6](06-Частые-правки.md).

## Картинки — `site/assets/images/`

```
images/
├─ products/            фото настоящих товаров (сейчас пусто; фото демо-товаров — в site/demo/)
├─ pages/               фото страниц
│  ├─ home/             hero.jpg — главный баннер, фон категорий, промо
│  ├─ about/            about-shop.jpg, gallery-1…6.jpg — «Жизнь магазина»
│  ├─ delivery/  login/
├─ common/              empty-state.png — «пусто», og-image.jpg — превью ссылки
└─ decor/               веточки-украшения по углам (PNG с прозрачным фоном)
```

Дополнительные ракурсы товара называются как главное фото с `-2` и `-3` на конце и лежат рядом с ним. Задание для нейросети на фото демо-товаров — в `prompts/IMAGES.md`.

## Демо-наполнение — `site/demo/`

Всё, что нужно только для показа, собрано в одной папке. С остальным сайтом она не связана: **удалите папку `demo` — и магазин запустится пустым**, без демо-товаров, отзывов, демо-аккаунтов и их фото. Подробно — в `site/demo/README.md`.

```
demo/
├─ README.md            как запустить магазин без демо
├─ data/
│  ├─ products.js       21 демо-товар
│  ├─ reviews.js        47 отзывов к ним
│  ├─ accounts.js       демо-аккаунты покупателя и администратора («Быстрый вход»)
│  └─ orders.js         демо-заказы
└─ images/products/     фото демо-товаров: face/, hair/, makeup/, body/, herbs/, sets/
```
