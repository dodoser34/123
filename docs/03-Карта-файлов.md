# 3. Карта файлов

Всё, что относится к сайту, лежит в папке `frontend/`. Правило простое: **HTML-страницы — в корне, стили — в `css/`, скрипты — в `js/`, картинки — в `assets/images/`**.

```
frontend/
├─ index.html, 404.html    ← главная и «страница не найдена» (обязаны лежать в корне)
├─ pages/                   ← остальные страницы: каталог, товар, корзина, вход…
├─ admin/index.html         ← админ-панель
├─ texts/                   ← ⭐ ВСЕ ТЕКСТЫ САЙТА, по файлу на раздел (см. texts/README.md)
├─ README.md                ← краткая техническая справка
├─ demo/                    ← ДЕМО-НАПОЛНЕНИЕ: товары, отзывы, демо-аккаунты, фото товаров (можно удалить целиком)
├─ css/                     ← оформление
├─ js/                      ← логика
└─ assets/images/           ← фотографии
```

## Страницы (HTML) — `frontend/` и `frontend/pages/`

| Файл | Что это | Пример адреса |
|---|---|---|
| `index.html` | Главная | `/index.html` |
| `pages/catalog.html` | Каталог | `/pages/catalog.html?cat=herbs` |
| `pages/product.html` | Страница товара. Какой именно товар — указано в адресе после `slug=` | `/pages/product.html?slug=romashka` |
| `pages/about.html` | О нас и контакты | `/pages/about.html` |
| `pages/delivery.html` | Доставка и оплата | `/pages/delivery.html` |
| `pages/cart.html` | Корзина | `/pages/cart.html` |
| `pages/checkout.html` | Оформление заказа | `/pages/checkout.html` |
| `pages/favorites.html` | Избранное | `/pages/favorites.html` |
| `pages/login.html` | Вход и регистрация; быстрый вход в демо-аккаунты (только локально и на GitHub Pages) | `/pages/login.html`, `/pages/login.html?mode=register` |
| `pages/account.html` | Личный кабинет | `/pages/account.html` |
| `404.html` | «Страница не найдена» | — |
| `admin/index.html` | Админ-панель | `/admin/index.html` |

> **Один шаблон на все товары.** Отдельного файла для каждого товара нет: `pages/product.html` по адресу понимает, какой товар показать. Поэтому новый товар из админки сразу получает свою страницу.

## Тексты — `frontend/texts/`

Все надписи сайта — заголовки, кнопки, подсказки, ошибки, вопросы-ответы — лежат в `frontend/texts/ru/`, по файлу на раздел:
`common.js` (шапка, подвал, карточка товара, уведомления), `home.js`, `catalog.js`, `product.js`, `about.js`, `delivery.js`,
`cart.js`, `checkout.js`, `favorites.js`, `login.js`, `account.js`, `not-found.js`. Как их править и как добавить другой язык —
в `frontend/texts/README.md`. Тексты о товарах и названия категорий сюда не входят: их меняют в админке.

## Демо-наполнение — `demo/`

Всё, что нужно только для показа, собрано в одной папке. С остальным сайтом она не связана: **удалите папку `demo` — и магазин запустится пустым**, без демо-товаров, отзывов, демо-аккаунтов и их фото. Подробно — в `demo/README.md`.

```
demo/
├─ README.md            как запустить магазин без демо
├─ data/
│  ├─ products.js       21 демо-товар
│  ├─ reviews.js        45 отзывов к ним
│  ├─ accounts.js       демо-аккаунты покупателя и администратора («Быстрый вход»)
│  └─ orders.js         демо-заказы
└─ images/products/     фото демо-товаров: face/, hair/, makeup/, body/, herbs/, sets/
```

## Весь проект целиком

Кроме сайта (`frontend/`), в проекте есть сервер, настройки публикации, тесты и документация:

```
проект/
├─ frontend/           сайт: то, что видит посетитель (описан выше)
├─ backend/            сервер (API): аккаунты, товары, заказы, оплата, база данных
├─ deploy/             запуск на своём сервере: Docker, Nginx, настройки, резервные копии
├─ docs/               эта документация
├─ tests/              тесты логики сайта (JS) и сборки публичной папки
├─ .github/workflows/  автоматические проверки и публикация в GitHub
├─ render.yaml         запуск на хостинге Render
└─ README.md           краткое описание проекта
```
