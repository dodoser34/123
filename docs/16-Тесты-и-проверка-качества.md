# 16. Тесты и проверка качества

**Тест** — маленькая программа, которая сама проверяет, что сайт ведёт себя правильно: например,
«если покупатель подменит цену в запросе, сервер всё равно возьмёт цену из базы».
Тесты запускаются одной командой и за пару минут проверяют то, что вручную заняло бы часы.

## Какие проверки есть

| Набор | Где | Что проверяет | Тестов |
|---|---|---|---|
| Основные функции сервера | `backend/tests/test_api.py` | регистрация, подтверждение почты, вход, профиль, товары, заказы, отзывы, фото | 11 |
| **Безопасность** | `backend/tests/test_security.py` | SQL-инъекции, XSS, права, перебор паролей и кодов, лимиты, заголовки, загрузка файлов, подпись оплаты, утечка секретов, настройки рабочего режима | 31 |
| Входные данные | `backend/tests/test_validation_cases.py` | границы и неверные значения во всех формах | 55 |
| Каталог | `backend/tests/test_catalog_cases.py` | категории, адреса товаров, фото сайта, тексты нельзя менять через API | 11 |
| База данных | `backend/tests/test_database_cases.py` | ограничения, уникальность, связи, каскадное удаление, откат | 24 |
| Сценарии заказов | `backend/tests/test_order_scenarios.py` | доставка, остатки, отмена, чужие заказы | 19 |
| Тестовая оплата | `backend/tests/test_sandbox_payments.py` | карта, отказ банка, Kaspi, только свой заказ, повторная оплата | 6 |
| Kaspi Pay | `backend/tests/test_payment_contract.py` | подпись и целая сумма в уведомлениях об оплате | 20 |
| Готовность к запуску | `backend/tests/test_readiness.py` | рабочий режим не стартует без базы, почты и настроек | 11 |
| Логика сайта (JS) | `tests/frontend/*.test.cjs` | экранирование, цены, маска телефона, ссылки, корзина, избранное, фильтры каталога | 78 |
| Сборка для публикации | `tests/general/test_public_build.py` | в `.public/` только публичные файлы, склейка стилей и пути к картинкам | 43 |
| Демо-версия | `demo/tests/` | сборка демо, все фото на месте, удаление демо | 22 |

**Всего 331 проверка (сервер — 188, сайт — 78, сборка — 43, демо — 22) — все проходят.** Тесты сервера работают на временной базе (каждый тест — с чистого листа);
письма не отправляются, платёжные сервисы не вызываются — их ответы имитируются.

## Как запустить

Сервер (из папки `backend`, после установки библиотек — [раздел 2](02-Как-запустить.md)):
```bash
.venv\Scripts\python -m pytest
```
Логика сайта (из корня проекта, нужен Node.js 20+):
```bash
node --test tests/frontend/*.test.cjs
```
Сборка для публикации (из корня проекта):
```bash
python -m pytest
```
Демо-версия:
```bash
python -m pytest demo/tests
```

## Автоматически в GitHub

При каждом изменении кода GitHub сам запускает проверки (`.github/workflows/`):

| Файл | Что делает |
|---|---|
| `backend.yml` | Тесты сервера **дважды**: на SQLite и на настоящем PostgreSQL; проверяет, что миграции применяются, совпадают с кодом и откатываются; что сервер без настроек не запустится в рабочем режиме |
| `checks.yml` | Синтаксис всех JS-файлов, тесты логики сайта, тесты сборки и сама сборка `.public/` |
| `pages.yml` | Сборка и публикация демо-версии на GitHub Pages |

Зелёная галочка у коммита в GitHub — все проверки прошли; красный крестик — открыть и посмотреть, что упало.

## Проверка в браузере

Кроме автотестов, сайт проверялся в настоящем браузере Chrome:
- все страницы и разделы админки — с сервером и в демо-версии, под гостем, покупателем и администратором, на телефоне и компьютере (более 300 открытий страниц) — без ошибок;
- сквозные сценарии: регистрация → подтверждение почты → заказ → оплата (перевод на Kaspi и тестовая оплата картой/Kaspi) → подтверждение администратором → удаление аккаунта;
- адаптивность на 20 размерах экрана — от телефона 320 px до 4K: нет горизонтальной прокрутки, вылезающих элементов и мелкого текста;
- склеенные для публикации стили дают точно такой же вид, как исходные.

## Проверить самому вручную

1. Запустить сайт с сервером ([раздел 2](02-Как-запустить.md)).
2. Зарегистрироваться (код — в `backend/dev-mail.log`), положить товар в корзину, оформить заказ с тестовой оплатой картой `4242 4242 4242 4242`.
3. Войти администратором — увидеть заказ «Оплачен» в админке.
4. Открыть сайт на телефоне (или Chrome → `F12` → значок телефона) и пройти то же самое.
