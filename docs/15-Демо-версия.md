# 15. Демо-версия

**Демо-версия** — отдельная витрина магазина для показа: тот же сайт, но **без сервера**, с примерами товаров, отзывов и заказов.
Публикуется на GitHub Pages и запускается локально. Настоящий магазин от неё не зависит.

## Что внутри — папка `demo/`

| Путь | Что это |
|---|---|
| `data/` | 21 примерный товар, 45 отзывов, демо-аккаунты, демо-заказы |
| `images/products/` | 65 фото примерных товаров |
| `runtime/` | Дополнения только для демо: быстрый вход, имитация оплаты картой, стартовое заполнение и обновления данных в браузере |
| `css/ui.css` | Оформление блока «Быстрый вход» |
| `config.json` | Какие дополнения подключать и под каким именем хранить данные в браузере |
| `build.py` | Сборка демо в `demo/.public/` (с проверкой, что все фото на месте) |
| `serve.py` | Локальный запуск: `python demo/serve.py` → http://localhost:5175 |
| `github-pages/action.yml` | Публикация на GitHub Pages (запускается из `.github/workflows/pages.yml`) |
| `seed_backend.py` | По желанию: загрузить примеры товаров в **локальную** базу сервера (на рабочем сервере запрещено) |
| `tests/` | Проверки сборки демо |

## Как работает

- Демо собирается из **тех же файлов сайта** (`frontend/`) плюс дополнения из `demo/runtime/`.
- Данные хранятся в браузере посетителя отдельно от основного сайта; сервера нет, реальных платежей и писем нет.
- **Быстрый вход:** покупатель `buyer@demo.kz` / `demo123`, администратор `admin@demo.kz` / `admin123`.
- «Забыли пароль?» работает с тестовым кодом **246810** — письма не отправляются.
- Оплата картой при оформлении — имитация прямо на странице заказа.

## Публикация на GitHub Pages

Один раз: в репозитории **Settings → Pages → Source: GitHub Actions**. Дальше демо публикуется само при каждом изменении `frontend/` или `demo/` в ветке `main`.

## Как убрать демо полностью

1. Удалите папку **`demo/`** целиком.
2. Удалите файл **`.github/workflows/pages.yml`**.

Основной магазин, сервер и их проверки работают без этих файлов. Уже опубликованная страница остаётся на GitHub до отключения в **Settings → Pages**.

## Что попадает в GitHub и на сервер

- В git хранятся исходники, документация, миграции, тесты и **образцы** настроек (`.env.example`).
- В git **не попадают** (правила — в `.gitignore` в корне, `backend/`, `deploy/`, `demo/`): файлы с паролями `.env`, локальные базы,
  журналы писем, загруженные фото, резервные копии, сборки `.public/`, кеши, окружения Python, настройки редакторов.
- Проверить правила: `git check-ignore -v deploy/.env backend/dev.db` — команда покажет, какое правило исключает файл.
- **На сервер** попадает только папка `.public/`, собранная `deploy/prepare_frontend.py`: страницы, стили, скрипты, тексты и картинки — без документации,
  тестов и служебных файлов.

> Если настоящий пароль когда-то попал в git, удаление файла не стирает его из истории — такой пароль нужно сменить.
