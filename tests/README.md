# Тесты проекта

Тест — маленькая программа, которая сама проверяет, что сайт ведёт себя правильно. Полное описание простыми словами — [docs/16-Тесты-и-проверка-качества.md](../docs/16-Тесты-и-проверка-качества.md).

| Папка | Что проверяет | Тестов |
|---|---|---|
| `tests/frontend/` | логика сайта на JavaScript: экранирование, цены, маска телефона, корзина, избранное, фильтры | 78 |
| `tests/general/` | сборка `.public/`: только публичные файлы, склейка стилей, пути к картинкам | 43 |
| `backend/tests/` | сервер: вход, заказы, оплата, база данных, безопасность | 188 |
| `demo/tests/` | демо-версия | 22 |
| **Всего** | | **331** |

## Как запустить

Логика сайта (из корня проекта, нужен Node.js 20+):
```bash
node --test tests/frontend/*.test.cjs
```
Сборка (из корня проекта):
```bash
python -m pytest
```
Сервер (из папки `backend`):
```bash
.venv\Scripts\python -m pytest
```
Демо-версия (из корня проекта):
```bash
python -m pytest demo/tests
```

## Как устроены

- Тесты JS загружают настоящие файлы сайта в изолированную «песочницу» с поддельным хранилищем браузера.
- Тесты сборки работают во временной папке и не трогают настоящую `.public/`.
- Тесты сервера работают на временной базе, которая создаётся заново для каждого теста; письма не отправляются, платёжные сервисы не вызываются.
