# K-Beauty | C-Health

Интернет-магазин корейской косметики и натуральных лечебных трав (Казахстан).
**Фронтенд** — чистые HTML, CSS и JavaScript без сборки. **Бэкенд** — Python, FastAPI и PostgreSQL.

**Сайт (демо):** https://dodoser34.github.io/123/

## Что где лежит

| Папка | Что внутри |
|---|---|
| `frontend/` | Сайт: страницы, стили, скрипты, админка |
| `frontend/pages/` | Страницы сайта (главная и 404 — в корне `frontend/`) |
| `frontend/texts/` | Все тексты сайта по разделам (их же можно править в админке → «Тексты сайта») |
| `frontend/env.js` | Адрес сервера: пусто — демо-режим, `/api` — работа с сервером |
| `frontend/demo/` | Демо-наполнение для режима без сервера |
| `backend/` | Сервер на FastAPI: аккаунты, каталог, заказы, отзывы, оплата Kaspi |
| `deploy/` | Запуск на своём сервере: Docker Compose, Nginx, HTTPS |
| `render.yaml` | Запуск на Render |
| `docs/` | Документация для непрограммистов — начните с `docs/00-Оглавление.md` |

Архитектура со схемами — [docs/12-Архитектура.md](docs/12-Архитектура.md), деплой — [docs/11-Бэкенд-и-деплой.md](docs/11-Бэкенд-и-деплой.md).
Как всё устроено простыми словами — [docs/16](docs/16-Как-это-работает.md), вопросы и ответы к защите — [docs/17](docs/17-Вопросы-и-ответы.md), тесты — [tests/README.md](tests/README.md).

## Возможности

- Регистрация с подтверждением почты кодом, вход по паролю, по коду из письма и через Google, выход, сброс пароля, удаление аккаунта.
- Пароли — хеш `bcrypt`. Администратор один, его почта и пароль задаются только в `deploy/.env` на сервере.
- Защита: лимиты попыток, защита от SQL-инъекций и XSS (CSP), заголовки безопасности, база во внутренней сети, ежедневные резервные копии — [docs/15](docs/15-Безопасность.md).
- Каталог, фильтры, отзывы, корзина, избранное, личный кабинет, админ-панель (товары, категории, заказы, отзывы, пользователи, тексты и фото сайта).
- Оплата: перевод на Kaspi владельца, наличные, готовый к включению Kaspi Pay — [docs/14](docs/14-Платежи.md).
- Смотреть сайт можно без регистрации; вход нужен для оформления заказа, личного кабинета, отзывов и админки.
- Демо-наполнение и быстрый вход в демо-аккаунты — только локально и на GitHub Pages.

## Быстрый старт

**Только сайт (демо, без сервера):**

```bash
python deploy/serve_frontend.py
```

Откройте http://localhost:5174. Демо-аккаунты: покупатель `buyer@demo.kz` / `demo123`, администратор `admin@demo.kz` / `admin123`.

**Сайт + сервер на своём компьютере** (без настроек и без PostgreSQL):

```bash
cd backend
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload --port 8000
```

База-файл `backend/dev.db` создаётся и заполняется демо-товарами сама; администратор — `admin@demo.kz` / `admin12345`, коды из писем — в `backend/dev-mail.log`.
В `frontend/env.js` впишите `window.KBCH_API_URL = 'http://localhost:8000/api';`. Документация API — http://localhost:8000/api/docs. Тесты — `python -m pytest`.

**Боевой запуск:** свой сервер с Docker — сайт, API и база PostgreSQL на одном сервере, все настройки в одном файле `deploy/.env` (образец `deploy/.env.example`); или Render (`render.yaml`). Пошагово — [docs/11](docs/11-Бэкенд-и-деплой.md).

## Публикация на GitHub

- `.github/workflows/pages.yml` — публичная сборка `.public/` из `frontend/` на GitHub Pages при каждом push в `main`; переменная репозитория `API_URL` подключает сервер.
- `.github/workflows/backend.yml` — тесты бэкенда при изменении `backend/`.
