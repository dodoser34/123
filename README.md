# K-Beauty | C-Health

Интернет-магазин корейской косметики и натуральных лечебных трав (Казахстан).
**Сайт** — HTML, CSS и JavaScript без сборки и фреймворков. **Сервер** — Python, FastAPI и PostgreSQL. **Публикация** — Docker, Nginx, HTTPS.

📖 **Вся документация — в папке [`docs/`](docs/00-Оглавление.md)**, написана для человека без опыта программирования.
В самом коде комментариев нет: все пояснения собраны в документации.

## Возможности

- Каталог с фильтрами и поиском, страница товара с отзывами, корзина и избранное — без регистрации.
- Регистрация с подтверждением почты кодом, вход по почте и паролю, «Забыли пароль?», личный кабинет, удаление аккаунта.
- Оформление заказа: доставка курьером, по Казахстану, самовывоз; оплата переводом на Kaspi, наличными,
  **тестовая оплата картой и через Kaspi** (имитация); готовый к подключению Kaspi Pay.
- Админ-панель: товары, категории, заказы и оплата, отзывы, пользователи, фото «О нас», готовность к запуску.
- Защита: хеши паролей, лимиты попыток, защита от SQL-инъекций, XSS, CSRF и DDoS, CSP, база во внутренней сети, ежедневные копии.
- Адаптивность от телефона 320 px до 4K, анимации появления, мозаика фото.

## Быстрый старт

Демо-версия с примерами товаров (без сервера):
```bash
python demo/serve.py
```
→ http://localhost:5175, вход `buyer@demo.kz` / `demo123` или `admin@demo.kz` / `admin123`.

Сайт с сервером на своём компьютере — [docs/02-Как-запустить.md](docs/02-Как-запустить.md).
