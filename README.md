# K-Beauty | C-Health

Интернет-магазин корейской косметики и натуральных лечебных трав (Казахстан). Чистые HTML, CSS и JavaScript, без сборки.

**Сайт:** https://dodoser34.github.io/123/

## Что где лежит

| Папка | Что внутри |
|---|---|
| `site/` | Сам сайт — именно он публикуется на GitHub Pages |
| `site/demo/` | Демо-наполнение: товары, отзывы, демо-аккаунты, демо-заказы и фото товаров. Удалите папку — и магазин запустится пустым (см. `site/demo/README.md`) |
| `docs/` | Документация для непрограммистов — начните с `docs/00-Оглавление.md` |
| `prompts/` | Задание для нейросети на фото сайта |
| `references/` | Макеты дизайна |

## Запуск у себя

```bash
python -m http.server 5173 --directory site
```

Откройте http://localhost:5173

## Публикация

Каждый push в `main`, который меняет `site/`, автоматически выкладывает сайт на GitHub Pages (`.github/workflows/pages.yml`). Один раз нужно включить: **Settings → Pages → Source: GitHub Actions**.

> Это фронтенд-демо: товары, заказы и аккаунты хранятся в браузере каждого посетителя. Для настоящего магазина нужен сервер — см. `docs/09-Ограничения-и-следующие-шаги.md`.
