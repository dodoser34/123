# Фото настоящих товаров

Сюда кладите фото товаров магазина, лучше по папкам разделов: `face/`, `hair/`, `makeup/`, `body/`, `herbs/`, `sets/`.

В админке в карточке товара укажите путь к файлу, например `assets/images/products/face/anua-toner.jpg`. Дополнительные ракурсы называйте так же, с `-2`, `-3` на конце: `anua-toner-2.jpg`.

Фото демо-товаров лежат отдельно — в `frontend/demo/images/products/` — и удаляются вместе с папкой `demo`.
