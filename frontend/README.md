# Основной фронтенд магазина

HTML, CSS и JavaScript магазина и админки. Данные и авторизация подключаются к API через `env.js`; при пустом адресе используется локальное хранилище без начальных товаров.

Запуск из корня проекта:

```powershell
python deploy/serve_frontend.py
```

Откройте `http://localhost:5174`. Для локального API укажите в `env.js`:

```javascript
window.KBCH_API_URL = 'http://localhost:8000/api';
```

В `frontend/` нет демонстрационных товаров, фотографий товаров, аккаунтов, имитации карточной оплаты или настроек GitHub Pages. Необязательная демонстрация вынесена в корневую папку `../demo/`; её запуск и удаление описаны в `../demo/README.md`.

## Структура

- `index.html`, `404.html`, `pages/` — страницы магазина.
- `admin/` — административная панель.
- `texts/ru/` — тексты интерфейса.
- `assets/` — изображения оформления и настоящие фото, добавленные владельцем.
- `css/` — общие стили, компоненты, страницы, адаптация и админка.
- `js/app.js` — загрузчик. Дополнительные модули могут подключаться конфигурацией отдельной сборки в `env.js`.
- `js/store/` — локальные данные, корзина, избранное; `remote.js` подключает API, `init.js` создаёт начальные категории.
- `js/core/` — тексты, форматирование, авторизация, запуск.
- `js/pages/`, `js/components/`, `js/admin/` — интерфейс страниц, компонентов и админки.

Production-сборка: `python deploy/prepare_frontend.py`. Она публикует только разрешённые файлы основного сайта в `.public/` и не включает необязательные модули.

Подробная документация — в `../docs/`.
